## Хэсэг A — Category-Partition

### A1 — Сонголт ба төлөөлөх утгууд

| Параметр / орчин | Сонголт (category) | Төлөөлөх утга |
|---|---|---|
| `from` | Дансны төлөв | Хүчинтэй (байгаа, царцаагүй) / Царцаагдсан / Байхгүй ID |
| `to` | Дансны төлөв, from-той харьцаа | Хүчинтэй, from-оос өөр / Байхгүй ID / from-той ижил |
| `amount` | Тэмдэг | Эерэг (> 0) / 0 / Сөрөг |
| `amount` + орчин | Үлдэгдэлтэй харьцуулсан (хөрвүүлсний дараа) | Бага / Яг тэнцүү / Их |
| `amount` + **далд орчин** | Өдрийн лимитийн үлдсэн хэсэгтэй харьцуулсан | Лимит дотор / Яг хүрнэ / Хэтэрнэ |
| `currency` | Дансны валюттай харьцуулсан | Ижил / Өөр (ханшаар хөрвүүлнэ) |

**Далд орчны сонголтууд:** from дансны үлдэгдэл, тухайн өдөр аль хэдийн шилжүүлсэн дүн (лимит хэр дүүрсэн), ханшийн утга. Эдгээр нь хүсэлтийн body-д байхгүй ч үр дүнг тодорхойлдог тул тест бүрийн setup-д тогтооно.
